ACADEMIC LAB VIVA VOCE PREPARATION

Information Retrieval Theory & Viva Guide

Complete mathematical reference, formulas, algorithms, and viva questions explaining how CivicFind implements modern Information Retrieval.

1

Text Preprocessing Pipeline

Converts raw unstructured text into canonical indexable tokens:

  • Tokenization: Regular expression parsing of alphanumeric terms.
  • Case Folding: Lowercasing to ensure case insensitivity.
  • Stop-word Removal: Removes high-frequency grammatical words (NLTK + custom domain stopwords).
  • Lemmatization: WordNet POS-aware morphological root extraction.
  • Stemming: Porter Stemmer suffix reduction algorithm.
2

Positional Inverted Index

Data structure mapping each vocabulary term to its postings list:

term → { doc_id: { tf: count, positions: [p1, p2, ...] } }

Enables $O(1)$ dictionary lookups, efficient phrase queries, and rapid Boolean set intersections.

3

Vector Space Model (TF-IDF)

Represents documents and queries as vectors in $V$-dimensional space:

TF(t, d) = 1 + log10(tf)
IDF(t) = log10((N + 1) / (df + 1)) + 1
cos(q, d) = (q · d) / (||q|| · ||d||)
4

Okapi BM25 Ranking Model

Non-linear probabilistic ranking function incorporating document length normalization:

BM25(q,d) = ∑ IDF(t) · [f(t,d)·(k1+1)] / [f(t,d) + k1·(1-b + b·|d|/L_avg)]

Tuning parameters: $k_1 = 1.5$ (term saturation), $b = 0.75$ (length penalty).

5

Query Reformulation & Rocchio

Improves retrieval effectiveness using explicit feedback and thesaurus:

q_new = α·q_0 + (β/|Dr|)·∑dr - (γ/|Dnr|)·∑dnr

Weights: $\alpha = 1.0, \beta = 0.75, \gamma = 0.25$.

6

IR Effectiveness Evaluation

Standard metrics used to quantify search quality:

  • P@K & R@K: Precision and Recall within top $K$ documents.
  • MAP: Mean Average Precision over all benchmark queries.
  • NDCG@K: Normalized Discounted Cumulative Gain with graded relevance (0, 1, 2).
  • MRR: Mean Reciprocal Rank ($1/\text{rank of first hit}$).

Frequently Asked Viva Voce Questions & Answers

Q1: Why is BM25 generally superior to basic TF-IDF Cosine Similarity?

Answer: Basic TF-IDF has unbounded term frequency growth. BM25 introduces term frequency saturation ($k_1$), so repeating a word 20 times doesn't give 20x score. Additionally, BM25 normalizes document length using parameter $b$ against the collection's average document length ($L_{avg}$), preventing unfairly penalizing or rewarding long or short documents.

Q2: What is the purpose of Latent Semantic Indexing (LSI) in CivicFind?

Answer: Traditional keyword search suffers from synonymy (different words with identical meaning, e.g., "grant" vs "scholarship") and polysemy. LSI computes Truncated SVD over the term-document matrix, mapping terms and documents into a lower-dimensional latent concept space ($k=25$). This enables retrieving documents that share underlying topic semantics even if exact words differ.

Q3: How is NDCG (Normalized Discounted Cumulative Gain) calculated?

Answer: NDCG handles graded relevance (e.g. 2 = Highly Relevant, 1 = Partially Relevant, 0 = Irrelevant). It discounts document gains logarithmically based on their rank: $\text{DCG}@K = \sum_{i=1}^K \frac{2^{rel_i} - 1}{\log_2(i + 1)}$. It is normalized by dividing by $\text{IDCG}@K$ (the Ideal DCG sorted descending), producing a score between 0.0 and 1.0.
